# HALT-HASS 循环监控与关闭流程实施计划

## 目标

本轮改造同时解决两个问题：

1. 循环测试页面以曲线为主要内容，在常用桌面分辨率下一屏尽量展示脉冲器、温度、振动三张曲线。
2. 软件倒计时归零后立即接管结束流程，不再等待循环工艺自行进入结束分支；完成停止、下电和连接释放后必须继续进入报告保存阶段。

## 已确认业务规则

- 页面采用左右布局：曲线在左，运行与设备状态在右。
- 左侧纵向展示三张曲线：
  - 脉冲器目标曲线与实际曲线。
  - 温度目标值与实际值。
  - 振动目标值与实际值。
- 单次任务约 4 小时；温度、振动数据在内存中保留约 6 小时，
  页面支持查看最近 5 分钟、1 小时、4 小时或全部记录。
- 图表按当前画布宽度对目标值和实际值做保峰降采样，原始接收数据不因
  页面绘图降采样而丢失。
- 右侧显示：
  - 配置总时间。
  - 剩余时间。
  - ITECH 6723 在线状态、电压和电流。
  - ITECH 3123 在线状态、电压和电流。
  - IFBOX 在线状态。
  - 脉冲器在线状态。
  - MQTT 连接状态及工作台状态。
- 右侧底部放置“运行/停止循环流”和“MQTT 设置”按钮。
- MQTT 设置使用独立弹层，运行期间可以查看但不能应用连接配置。
- 移除“曲线优先”文字。
- 移除本页“暂存”入口及对应事件链路；历史暂存工单仍保留读取兼容。
- 软件倒计时归零即视为循环测试到时：
  1. 停止当前 Flojoy 拓扑。
  2. 执行独立的 HALT-HASS 关闭流程。
  3. 关闭 6723、3123 输出并停止工作台。
  4. 释放连接。
  5. 生成报告并进入报告保存/上传阶段。
- 关闭流程不等待循环工艺自身的结束节点。

## Close 条件

以下条件全部满足后，本计划可关闭：

- 倒计时归零后不再等待工艺结束，立即启动停止与下电。
- 下电成功后稳定进入报告保存/上传阶段。
- 页面在常用桌面窗口内可同时看到三张曲线和右侧关键状态。
- 不再显示暂存按钮和“曲线优先”文字。
- 自动化检查和生产构建通过。

## 当前状态

代码实现与自动化验证已完成。由于自动化环境不能代替真实电源和工作台执行下电，
计划暂不 Close；完成一次现场短时工单闭环验证后即可关闭。
