# HALT-HASS SDS 业务流程与人工验收清单

## 验收结论

SDS 按“工单识别、客户端选工艺、13 板装配、设备绑定、测试流、MQTT 循环流、结束下电、逐板报告”的顺序实现和验收。当前客户端只完成 SDS 类型分流、工艺加载、工艺参数结构和部分 ECHO 节点，尚不能执行完整 SDS 测试。

本清单只覆盖 SDS 475 全套液压方式。局部系统加电子负载和局部系统加液压方式不在本次范围内。现场测试必须等所有阻塞项补齐并通过隔离测试后再进行。
