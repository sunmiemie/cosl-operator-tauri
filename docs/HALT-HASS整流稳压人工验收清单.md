# HALT-HASS 整流稳压人工验收清单

## 验收结论

整流稳压功能按本清单顺序验收。数据库、工艺、工单、装配和报告页面通过后，现场人员再执行真实设备检查。任何设备角色或序列号不明确时，停止带电检查。

审核人填写每项的结果和问题编号。所有必检项通过后，功能可进入现场试运行。

## 验收范围

本清单覆盖客户端工艺编辑、工单选择、板卡装配、设备绑定、MQTT 流程、整流稳压采集、客户端报告确认、管理端审核和 Word 下载。

SDS 475 全套液压业务使用独立的 [HALT-HASS SDS 业务流程与人工验收清单](./HALT-HASS-SDS业务流程与人工验收清单.md)，按工单、工艺、13 板装配、7 项通信、循环流和逐板报告的顺序审核。

小助手接口、故障报告和生产环境发布不在本次验收范围内。真实设备检查仅验证当前功能，不替代设备操作规程和电气安全确认。
